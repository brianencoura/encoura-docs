# Buttons

The `Button` component is a polymorphic button that renders as a `<Link>`, `<a>`, `<button>`, `<div>`, or `<span>` depending on the `tag` prop. It uses `class-variance-authority` (CVA) for variant management and `tailwind-merge` for class composition.

## Import

```js copy
import Button from "@/components/atoms/Button";
```

---

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `ButtonVariants` | `"primary"` | Visual style of the button |
| `tag` | `"Link" \| "button" \| "a" \| "div" \| "span"` | `"Link"` | The HTML element or Next.js Link to render |
| `href` | `string` | — | Required when `tag="Link"` or `tag="a"` |
| `target` | `string` | — | Link target (e.g. `"_blank"`) |
| `className` | `string` | — | Additional classes merged via `twMerge` |
| `arrowClassName` | `string` | — | Classes applied to the arrow icon in arrowed variants |
| `rel` | `string` | — | Rel attribute for anchor elements |
| `urlForwardedParams` | `{ sourceParamKey: string; targetParamKey: string }[]` | — | Forwards URL query params from the current page to the link `href` |

---

## Variants

All variants are built from shared base classes with variant-specific additions.

### Shared Base Classes

**Block base** — used by `primary`, `outline`, `white`, `white-border`, `default`:

```text copy
inline-block font-bold px-7 rounded cursor-pointer active:scale-90
```

**Arrow base** — used by `arrowed`, `arrowed-toggle-underline`, `arrowed-toggle-underline-white`, `arrowed-alt`:

```text copy
inline-flex gap-2 items-center text-current font-bold cursor-pointer group active:scale-90 ease-in-out duration-300
```

**Underline base** — used by `arrowed-toggle-underline` and `arrowed-toggle-underline-white` (in addition to arrow base):

```text copy
mt-auto relative items-start after:content-[''] after:w-0 after:ease-in-out after:duration-500 after:absolute after:left-0 after:bottom-[-4px] after:bg-orange after:h-[2px] group-hover:text-orange group-hover:after:w-[78%]
```

### Primary

Solid orange background. The default call-to-action button.

<div className="mb-5">
  <a className="inline-block text-white px-7 pt-[14px] pb-3 m-0 bg-[#cf4a29] rounded cursor-pointer border-2 border-[#cf4a29] font-bold duration-700 ease-in-out hover:rounded-[50px] active:scale-90" href="#">Primary Button</a>
</div>

```jsx copy
<Button variant="primary" href="/some-path">
  Primary Button
</Button>
```

**Variant-specific classes** (+ block base):

```text copy
text-white pt-[14px] pb-3 m-0 bg-orange border-2 border-orange duration-700 ease-in-out hover:rounded-[50px] active:bg-orange-darker
```

### Arrowed

Inline text link with an animated arrow icon. Arrow rotates 45° on hover.

<div className="mb-5">
  <a className="inline-flex gap-2 items-center text-[#cf4a29] font-bold cursor-pointer group active:scale-90 ease-in-out duration-300" href="#">
    Learn More
    <svg xmlns="http://www.w3.org/2000/svg" width="15" height="15" viewBox="0 0 24 24" className="fill-[#cf4a29] inline-block" style={{transform: "rotate(0deg)", transition: "transform 300ms ease-in-out"}}><path d="M5 3l3.057-3 11.943 12-11.943 12-3.057-3 9-9z"/></svg>
  </a>
</div>

```jsx copy
<Button variant="arrowed" href="/some-path">
  Learn More
</Button>

{/* Custom arrow color */}
<Button variant="arrowed" href="/some-path" arrowClassName="fill-navy-blue">
  Learn More
</Button>
```

Uses **arrow base** only — no additional variant-specific classes.

---

### Arrowed Toggle Underline

Arrow link with an animated underline that expands on parent hover. Designed for use inside a parent element with the `group` class. Text turns navy-blue on parent hover.

```jsx copy
{/* Parent must have className="group" */}
<div className="group">
  <Button variant="arrowed-toggle-underline" href="/some-path">
    Learn More
  </Button>
</div>
```

**Variant-specific classes** (+ arrow base + underline base):

```text copy
group-hover:!text-navy-blue
```

---

### Arrowed Toggle Underline White

Same as `arrowed-toggle-underline` but text turns white on parent hover. Use on dark backgrounds.

```jsx copy

<div className="group bg-navy-blue p-4">
  <Button variant="arrowed-toggle-underline-white" href="/some-path">
    Learn More
  </Button>
</div>
```

**Variant-specific classes** (+ arrow base + underline base):

```text copy
group-hover:!text-white
```

## Builder.io Usage

The `Button` component is registered in Builder as **"Button"**. The content team can add it from the Insert panel in the Builder visual editor.

### Available Fields

| Field | Type | Default | Visibility | Description |
|-------|------|---------|------------|-------------|
| **Variant** | Select | `primary` | Always | Visual style — one of: `primary`, `outline`, `white`, `arrowed`, `arrowed-toggle-underline`, `arrowed-toggle-underline-white`, `arrowed-alt`, `white-border`, `default` |
| **Tag** | Select | `Link` | Always | Underlying element — `Link`, `button`, `a`, `div`, or `span` |
| **Link** (`href`) | URL | `https://google.com/` | When Tag = `Link` | Destination URL for the button |
| **Text** (`children`) | String | `"Button"` | Always | The button label text |
| **URL Forwarded Params** | List | — | When Tag = `Link` | Forwards query params from the current page URL to the link (see below) |
| **Arrow Class Name** | String | `"arrow"` | Advanced | Custom class for the arrow icon in arrowed variants |
| **rel** | String | — | Advanced | Anchor `rel` attribute (e.g. `"noopener noreferrer"`) |
| **target** | String | — | Advanced | Anchor `target` attribute (e.g. `"_blank"`) |

### URL Forwarded Params

Each entry in the list has two fields:

- **sourceParamKey** — The query param key to read from the current page URL (e.g. `"source"` reads from `www.encoura.org?source=123`)
- **targetParamKey** — The query param key to append to the button's `href` (e.g. `"target"` produces `www.targetLink.com?target=123`)

### Quick Reference for Content Team

1. **Insert** the Button component from the Builder insert panel
2. **Pick a variant** from the dropdown — preview updates live
3. **Set the link** URL if using the default `Link` tag
4. **Type the label** in the Text field
5. For buttons that trigger JS actions (no navigation), change **Tag** to `button`
6. To open links in a new tab, expand **Advanced** and set **target** to `_blank`
7. To pass tracking params through, add entries to **URL Forwarded Params**

## Rendering as a non-link element

Use the `tag` prop to render a native `<button>`, `<div>`, or `<span>` instead of a Next.js `<Link>`. This is useful for buttons that trigger JS actions rather than navigation.

```jsx copy
{/* Native button element */}
<Button variant="primary" tag="button" onClick={handleClick}>
  Submit
</Button>

{/* Div wrapper (no navigation) */}
<Button variant="outline" tag="div">
  Label
</Button>
```

---

## Forwarding URL params

`urlForwardedParams` copies query parameters from the current page URL into the button's `href`. Useful for preserving UTM or tracking params across navigation.

```jsx copy
<Button
  variant="primary"
  href="/signup"
  urlForwardedParams={[
    { sourceParamKey: "utm_source", targetParamKey: "utm_source" },
    { sourceParamKey: "ref", targetParamKey: "ref" },
  ]}
>
  Sign Up
</Button>
```
