# Breakpoints

Encoura uses custom Tailwind breakpoints that extend the defaults with two additional small-screen sizes (`xxs` and `xs`). All breakpoints are mobile-first (`min-width`).

## Breakpoint Scale

| Token | Min Width | Tailwind Prefix | Typical Target |
|-------|-----------|-----------------|----------------|
| `xxs` | 340px | `xxs:` | Small phones (SE, Galaxy Fold) |
| `xs` | 440px | `xs:` | Standard phones |
| `sm` | 640px | `sm:` | Large phones / small tablets |
| `md` | 768px | `md:` | Tablets (portrait) |
| `lg` | 1024px | `lg:` | Tablets (landscape) / small laptops |
| `xl` | 1280px | `xl:` | Desktops |
| `2xl` | 1536px | `2xl:` | Large desktops |

## Tailwind Config

```js copy
screens: {
  xxs: "340px",
  xs: "440px",
  sm: "640px",
  md: "768px",
  lg: "1024px",
  xl: "1280px",
  "2xl": "1536px",
},
```

## Usage

Breakpoints are mobile-first, meaning unprefixed utilities apply to all screen sizes and prefixed utilities apply at that breakpoint **and above**.

```jsx copy
{/* Full width on mobile, half on tablet, third on desktop */}
<div className="w-full md:w-1/2 xl:w-1/3">
  ...
</div>

{/* Hidden on small screens, visible from md up */}
<nav className="hidden md:block">
  ...
</nav>

{/* Stack on mobile, row from sm up */}
<div className="flex flex-col sm:flex-row gap-4">
  ...
</div>
```

## Notes

- `xxs` and `xs` are custom additions — they are not part of Tailwind's default breakpoint set
- The `sm` through `2xl` values match Tailwind's defaults
- When designing in Builder, keep these breakpoints in mind for responsive visibility and layout decisions
